طريقة التشغيل:
1) افتح مجلد estidama-site في Visual Studio Code (File > Open Folder).
2) ثبّت إضافة Live Server، ثم كليك يمين على index.html واختر Open with Live Server.

الصفحات: index (الرئيسية) - about - services - programs - community - trainers - news - request - contact
كل صفحة ملف HTML مستقل، والهيدر والفوتر مشتركان وموجودان في script.js (دالة buildLayout).
المحتوى (المدربون، البرامج، الأخبار، الشركاء) في data.js.
